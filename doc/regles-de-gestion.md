## Application mobile (globalité)

RG1 : L'application mobile doit être développée  
RG2 : L'interface utilisateur doit privilégier une approche Mobile-First  
RG3 : L'accès aux fonctionnalités d'achat de produits ne doit PAS imposer la création d'un compte  
RG4 : L'application doit contenir une section présentant l'activité du client  
RG5 : L'application doit contenir une section présentant l'expérience passée du client  
RG6 : L'application doit contenir le logo de l'entreprise du client  
RG7 : L'application doit contenir un "menu burger" cliquable  
RG8 : Le "menu burger" de l'application doit contenir ses autres onglets/pages  

## Boutique de "goodies"  


RG9 : La boutique doit présenter les produits phares uniquement  
RG10 : Une dizaine de produits maximum devront être présentés  
RG10 : Chaque produit devra inclure la photo, le titre, une description et un prix  
RG11 : Le titre d'un produit devra tenir en quelques mots  
RG12 : La description d'un produit devra être rédigée d'une longueur de 5 lignes maximum  
RG13 : Le prix d'un produit devra toujours afficher le tarif en Euros (€)  
RG14 : Le paiement d'une commande devra s'effectuer via PayPal  
RG15 : Sur PayPal, une commande ne pourra pas être honorée si les renseignements demeurent incomplètes  
RG16 : Le numéro de carte bancaire ne devra être stockée nulle part
