## Application mobile (globalité)

RG1 : L'application mobile doit être développée pour une interface Android uniquement    
RG2 : L'interface utilisateur doit privilégier une approche Mobile-First  
RG3 : L'accès aux fonctionnalités d'achat de produits ne doit PAS imposer la création d'un compte  
RG4 : La saisie d'un email et d'une adresse de facturation reste obligatoire lors de l'achat via un formulaire  
RG4 : L'application doit contenir une section présentant l'activité du client  
RG5 : L'application doit contenir une section présentant l'expérience passée du client  
RG6 : L'application doit contenir le logo de l'entreprise du client  
RG7 : L'application doit contenir un "menu burger" cliquable  
RG8 : Le "menu burger" de l'application doit contenir l'intitulé de ses autres onglets/pages  

## Boutique de "goodies"  

RG9 : La boutique doit présenter les produits phares uniquement  
RG10 : Une dizaine de produits maximum devront être présentés  
RG10 : Chaque produit devra inclure la photo, le titre, une description et un prix  
RG11 : Le titre d'un produit devra tenir en quelques mots  
RG12 : La description d'un produit devra être rédigée d'une longueur de 5 lignes maximum  
RG13 : Le prix d'un produit devra toujours afficher le tarif en Euros (€)  
RG14 : Le paiement d'une commande devra s'effectuer via PayPal 
RG15 : En cas d'indisponibilité de PayPal, une alternative de paiement devra être proposée (Stripe)   
RG15 : Sur PayPal, une commande ne pourra pas être honorée si les renseignements demeurent incomplètes   
RG16 : Le numéro de carte bancaire ne devra être stockée nulle part  

## Partie Jeu de Rôle (JDR)  
### Réservation de partie  

RG17 : Le JDR devra avoir un onglet dédié au sein de l'application  
RG18 : Le présentateur du JDR est appelé "MJ", ou "Maître du Jeu"  
RG18 : Cet onglet devra présenter le JDR de façon détaillée   
RG19 : Cet onglet devra indiquer un formulaire de réservation  
RG20 : Ce formulaire permettra aux joueurs de réserver un créneau pour leur future partie  
RG21 : La réservation devra être individuelle (1 formulaire par joueur)  
RG22 : Les futurs joueurs devront indiquer leur niveau d'expérience auprès du MJ  

### Crowdfunding  
RG23 : L'application doit contenir un onglet ou une page spécifiquement dédiée au crowdfunding du JDR  
RG24 : Cette section doit présenter le contexte narratif et l'univers du JDR  
RG25 : Cette section doit comporter des visuels / illustrations représentatif du JDR  
RG25 : Cette section doit comporter un bouton d'appel à l'action bien visible  
RG26 : Le bouton doit renvoyer vers une page de donation / financement  
RG27 : L'entièreté de la section devra disparaître / remplacée lors de la fin de la campagne de financement
